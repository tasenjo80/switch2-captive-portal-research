# Security and data policy

## Reporting

Use GitHub's private vulnerability reporting for security issues. Do not open
a public issue with credentials, keys, private data, or a working exploit.

For a data-removal request, contact the repository owner through GitHub. Do
not include personal data in a public issue.

## Scope

This repository contains documentation only. It does not contain firmware,
keys, game dumps, save data, console binaries, raw logs, or an exploit. It is
not a jailbreak, CFW, or piracy project.

## Supported versions

Only the current `master` branch is supported.
