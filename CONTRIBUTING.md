# Contributing

This repository is a sanitized research log. Corrections and reproducible
observations are welcome.

## Good contributions

- A correction with a source and a date.
- A reproducible observation with the console model, firmware, network setup,
  exact steps, and what happened.
- A public source link that clarifies a claim.

## Do not contribute

- Exploit code, heap-grooming code, trigger pages, or payloads.
- Raw logs, screenshots, full IPs, MAC addresses, SSIDs, serials, account
  identifiers, or personal paths.
- NPDM/NCA/NSP/XCI/NRO/NSO files or any console binary.
- Discord exports, private messages, or invite links.
- Unverified claims presented as confirmed facts.

## Labels

Use "verified on hardware", "public source", or "community/unverified" in the
description. Do not mix them.

## Issues

Open an issue with the relevant template. For security or data-removal
requests, follow [SECURITY.md](SECURITY.md) instead of a public issue.
